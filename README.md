# Network IP Checker

Ferramenta web para diagnóstico básico de equipamentos de rede IPv4.

A aplicação permite verificar um endereço IP e obter informações sobre:

- Status de conectividade
- Tempo de resposta (ping)
- Hostname
- Estado de portas e serviços

## Tecnologias

- Python
- FastAPI
- JavaScript
- HTML
- CSS
- Netcat
- Avahi

## Requisitos

- Python 3.12 ou superior
- Linux
- Netcat (`nc`)
- Avahi (`avahi-resolve-address`)
